# Contributing to Campus QuickSplit

Thank you for your interest in contributing to Campus QuickSplit.

## Before You Start

Please open an issue before starting a significant change. Describe:

- What you want to change
- Why the change is useful
- Any relevant implementation details

For small fixes such as documentation corrections or obvious bugs, you may submit a pull request directly.

## Development Setup

Make sure you have:

- Flutter 3.44.0 or later
- Dart SDK 3.12.0 or later
